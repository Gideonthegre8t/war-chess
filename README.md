# Kingdoms at War

A cinematic multiplayer chess game where the chessboard is the primary gameplay and a live medieval warzone visualizes every move as a battlefield command.

## Documentation

See [docs/DOCUMENTATION.md](docs/DOCUMENTATION.md) for full project documentation including:
- Architecture
- MVP Progress
- Phase 1 (Completed) - Chess Engine
- Phase 2 (Current) - Multiplayer Infrastructure
- Phase 3 (Future) - War Engine

## Current Stack

| Technology | Purpose |
|------------|---------|
| React 19 | UI |
| Vite | Build tool |
| JavaScript (JSX) | Current language |
| CSS3 | Styling |
| chess.js | Chess engine |
| Git + GitHub | Version control |

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run linting
npm run lint
```
